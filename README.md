# 🚗 Car Wash Management System

A desktop application for managing a car wash business, developed using **C#**, **.NET Framework (WinForms)**, **SQL Server**, and **ADO.NET** following the **Three-Tier Architecture**.

## 🚀 Features

### 👥 Customer Management
- Add, edit, delete  customers.
- Store customer and vehicle information.

### 👨‍💼 Employee Management
- Add, edit, delete employee
- Employee status management.

### 🚗 Service Management
- Manage available car wash services.
- Set service prices.
- Add and delete services.

### 💳 Billing & Transactions
- Create new billing records.
- Select customer, employee, and service.
- Store payment information.

### 📊 Dashboard
- Total Customers
- Total Employees
- Total Revenue
- Total Transactions
- Most Required Services
- Weekly Revenue Overview Chart

### ✅ Validation
- ErrorProvider validation.
- Required fields validation.
- User-friendly messages.

### ⚠️ Exception Logging
- Log application exceptions using **Windows Event Viewer**.
